DSH Desktop · 桌面工作台

桌面端的 DeepSeek Harness

Electron 原生壳 + 内嵌 harness 运行时。离线、免装 Node、免全局 dsh，双击即可开始。

壳只保留桌面原生能力（窗口、托盘、全局快捷键、深链、自动更新），加载官方 Web UI； 与 harness 之间仅通过一个桥接插件通信——不注入 UI、不持有面板代码。

Agent = Model + Harness

DSH Desktop = Shell + Harness

模型是 Agent 的灵魂，Harness 给予 Agent 理解环境、使用工具、在真实场景中持续工作的能力。 DSH Desktop 把这些能力装进一个桌面壳里：本地启动 harness 运行时，加载官方 Web UI， 再补上全局快捷键、托盘、深链这些「桌面才有的」体验。

NATIVE SHELL

原生桌面能力

窗口、托盘、系统通知、任务栏徽标、开机自启。壳只负责桌面原生部分，不持有任何 UI 代码。

EMBEDDED RUNTIME

内嵌 harness 运行时

安装包内置便携 Node 与 dsh 运行时，首次启动自动解压并创建 desktop profile，离线即可使用。

BRIDGE PLUGIN

桥接插件通信

壳与 harness 之间仅通过 dsh-desktop-bridge 插件通信：后台任务与审批事件转成系统通知与徽标。

设计思路：能力各归其位，体验无缝衔接

壳 + Harness

壳以 dsh --profile desktop --patch <overlay> --port 0 拉起运行时并加载官方 Web UI（会话、工作区、插件、设置）， 端口自动分配，无冲突。专用的 desktop profile 位于 $DSH_HOME/profiles/desktop，与 Web / CLI 共享同一份 ~/.dsh 数据。

每一次唤出都有迹可循

任意界面按 Ctrl+Shift+Space 全局唤出/隐藏窗口；点击 dsh:// 深链可直接聚焦、新建会话或打开指定会话。 关闭窗口默认最小化到托盘，右键托盘可切换工作区、重启 Harness、查看日志、检查更新。

开箱即用的桌面体验

🪟

原生窗口

加载官方 Web UI，--port 0 自动分配端口，无端口冲突。

⌨️

全局快捷键

默认 Ctrl+Shift+Space，任意界面一键唤出。

🔗

深链唤起

dsh:// 聚焦、dsh://new 新建、dsh://session/<id> 打开会话。

🗂️

托盘常驻

关闭即最小化，托盘右键管理工作区、日志与更新。

⬆️

自动更新

内置自动更新，新版本静默下载、重启生效。

🛡️

崩溃自愈

运行时异常自动拉起，托盘常驻不打扰。
