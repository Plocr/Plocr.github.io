写了这么久博客，不如写一篇教程给自己——免得以后忘了怎么操作。

---

## 第一步：本地新建文章

在博客项目根目录打开终端：

```bash
cd "F:\文档\GitHub blog\Plocr.github.io"
```

用 Hexo 新建一篇 Markdown 文章：

```bash
npx hexo new "文章标题"
```

这会在 `source/_posts/` 下生成一个 `.md` 文件。打开它，顶部有一段叫 **Front-matter** 的配置区域：

```markdown
---
title: 文章标题
date: 2025-05-15
tags: [项目日志]
---

正文从这里开始...
```

| 字段 | 说明 | 必填 |
|------|------|------|
| `title` | 文章标题 | 是 |
| `date` | 发布日期 | 是 |
| `tags` | 标签（四选一）：项目日志 / 工作流分享 / 随笔 / 影音推荐 | 推荐 |
| `excerpt` | 摘要，显示在首页卡片上 | 推荐 |

---

## 第二步：写内容

用 Markdown 语法写正文。常用格式：

```markdown
## 二级标题

### 三级标题

这是**粗体**，这是*斜体*。

> 引用文字

- 列表1
- 列表2

[链接文字](https://...)

![图片描述](图片URL)
```

图片建议用在线图床链接，不要放本地文件。

---

## 第三步：本地预览

写完后在本地看看效果：

```bash
npx hexo server
```

浏览器打开 `http://localhost:4000`，找到你的文章点进去。如果哪里不对，回到 `.md` 文件修改，保存后刷新页面即可看到变化。

---

## 第四步：提交并推送

确认没问题后：

```bash
git add -A
git commit -m "新文章：文章标题"
git push origin master
```

推送后，Vercel 会自动检测到 `master` 分支的更新，开始构建并部署到 [plocr.online](https://www.plocr.online/)。

---

## 第五步：等一会儿

Vercel 构建通常需要 1-2 分钟。去 [Vercel Dashboard](https://vercel.com) 可以实时看到构建进度。构建完成后，你的文章就在线了。

---

## 常见问题

> **推送后网站没变化？**
> 去 Vercel 看部署日志。如果失败，大概率是 Markdown 语法错误。

> **本地 `hexo s` 报错？**
> 检查 Front-matter 的格式，`---` 必须成对出现。

> **标签不对？**
> 标签只能从四个分类里选：`项目日志`、`工作流分享`、`随笔`、`影音推荐`，用其他的不会出现在归档分类里。

> **文章没有封面？**
> 有图就用第一张，没图就随机分配 12 种手绘插画之一，不用担心。
