关于这个博客

一个安静的个人博客。

记录一些项目日志、工作流分享、偶尔的胡思乱想，还有喜欢的电影和音乐。不追求流量，不追逐热点，写给自己，也写给偶然路过的人。

博客使用 Markdown 写作，推送即部署，省心。

关于我

一个喜欢折腾的开发者。对技术保持好奇，对生活保持感知。

写代码、看电影、听歌、偶尔拍照。认为好的工具应该像手写一样自然。

致谢

这个博客能运行起来，离不开以下开源项目和免费服务。在此致谢。

框架与工具

  • Hexo — 快速、简洁的静态博客生成器，驱动整个博客
  • Hexo 主题自定义 — 基于 Hexo 模板系统自研主题
  • 小濑字体 (Xiaolai Mono SC) — 落霞孤鹜制作的开源中文字体，免费可商用
  • Fantasque Sans Mono — 等宽编程字体，用于代码块
  • Font Awesome — 图标库
  • 不蒜子 — 轻量级网站统计，提供阅读量计数
  • Giscus — 基于 GitHub Discussions 的开源评论系统

API 与数据

  • 一言 (Hitokoto) — 首页名言随机展示
  • TMDB — 电影封面图源
  • jsDelivr — 开源 CDN 加速服务

部署

  • GitHub Pages — 免费静态网站托管
  • GitHub Actions — 自动化构建与部署

设计灵感

  • Claude 设计语言 — 低饱和莫兰迪色系与手绘风格灵感来源
  • SVG 插画中的手绘粗糙质感基于 feTurbulence SVG 滤镜实现

感谢所有开源贡献者和免费服务的提供者。
